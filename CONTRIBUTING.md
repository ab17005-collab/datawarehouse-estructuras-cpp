
# Reglas de colaboración

1. Cada integrante trabajará en su propia rama.
2. No se modificará directamente la rama main.
3. Cada módulo tendrá sus archivos separados.
4. Los cambios se integrarán mediante Pull Requests.
5. El código deberá compilar antes de fusionarse.
6. Cada integrante documentará su módulo.
7. Los commits tendrán mensajes descriptivos.
8. No se subirán ejecutables ni archivos temporales.
9. Los cambios en archivos compartidos se coordinarán.
