
# Estructuras de Datos No Lineales en Data Warehouse

Proyecto académico desarrollado en C++.

## Descripción

Aplicación de consola que demuestra el uso de estructuras
de datos no lineales en un Data Warehouse de ventas.

## Módulos

1. Cubo OLAP con jerarquía de tiempo.
2. Árbol B+ sobre una tabla de hechos.
3. Grafo de procesos ETL con BFS y DFS.

## Tecnologías

- C++17
- CMake
- Git y GitHub
- UML

## Compilación

```bash
cmake -S . -B build
cmake --build build
```

## Integrantes

- Integrante 1: Cubo OLAP
- Integrante 2: Árbol B+
- Integrante 3: Grafo ETL
